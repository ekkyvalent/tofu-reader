Flashing instructions

SD card update (recommended, no cable)
  1. Download the app image above.
  2. Copy it to the SD card. Any folder works, the base name is irrelevant, the extension must stay .bin.
  3. Put the card back in the reader.
  4. On the device open Settings, System, SD Card Firmware Update and pick the file.
  5. The reader validates the image, writes the inactive slot, and reboots into it. This takes a few minutes and the screen shows progress.

The menu entry only exists on CrossPoint-based firmware recent enough to ship it. If "SD Card Firmware Update" is not in the menu, use the browser flasher below.

To go back, update again with the upstream CrossPoint image. The old build stays in the other slot.

Browser flasher (desktop Chrome, needs USB)
  1. Open crosspointreader.com flash tools.
  2. Choose the "Custom .bin / Upload file" option.
  3. Select the app image file listed above.

The factory image is a merged bootloader, partition table and app image for writing at address 0x0. It is the wrong file for the browser flasher path.
